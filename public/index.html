📖 总体思想（系统宪法）

把控制论的负反馈闭环套在自己身上。本页定义"为什么"，其他页定义"怎么做"。

1. 规则树：根部 / 中层 / 顶层

根部= 傻瓜级保命定式（脑子浆糊也能做）；中层= 状态正常时的推进动作；顶层= 巅峰冲刺目标。崩塌日只保根部，满血日够顶层。

胜于易胜：根部定式必须小到不可能失败。

2. 不可逃逸区

「躺床 + 深夜 + 手机解锁」区内意志力失效。唯一解是环境改造：22:30 手机放客厅 = 让区不存在。不要在区内战斗。

3. 崩塌即调试（定式迭代台就是干这个的）

崩溃是系统报错不是道德失败。响应协议：迭代台记录 → 修改定式 → 次日重启。不归零、不连签绑架、累计完成 > 连续天数。

崩溃 → 迭代台记录(关联定式) → 修改/降级该定式 → 恢复执行 ↑____________ 迭代闭环 ____________↓

4. CTDP 三原理

  • 神圣座位：用"记录不可玷污"制造沉没成本，坐上去只做正事。
  • 下必为例：破例的代价 = 永久放弃整条规则，所以定式要设得保守。
  • 线性时延：冲动来时预约 15 分钟后（冷却计时器），骗过短视的大脑。

5. 负反馈环阻断

晚睡刷手机 → 夜宵 → 肠胃不适 → 更难入睡。断点：「22:30 手机放客厅」+「清醒不吃零食」。环上任一环断，整环失效。

6. 环境耦合 & 日标记

床=堕落区，图书馆=Buff区。社交日/高扰动日/低能量日用日标记标注，带「降级」属性的标记自动激活降级协议：只做侦查任务，不追责。

7. 可选工具箱（非义务）

  • 1动作法则：状态极差日只推进 1 个最小产出，保命用。
  • 15分钟冷却 / 25分钟视频熔断：应急协议按钮。
  • 两分钟规则：不想学时只承诺做 2 分钟，启动后大概率继续。

8. 支链：允许走 B 计划，且不扣分

规则可以挂支链（B 计划）。主链节点崩了，支链自动激活顶上；未激活的支链不计入进度分母，所以走 B 计划不会掉完成率。

消灭"反正今天已经废了"——这句话才是真正的杀手。

9. 迭代协议

日：打勾 + 打标记 + 记事件（30秒内）+ 日复盘一句话 周：柱状图 + 周复盘三问 → 迭代台改规则 → 导出周报喂 AI 月：热力日历趋势 + 月复盘 → 失效规则降级或删除 阶段：系统统计 + 主观日志 → 下一阶段开新分支

你是自己人生的运维工程师。改规则 = 发版本。
